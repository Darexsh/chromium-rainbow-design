# Google chrome rainbow dark design
Installation instructions:
- Open Google chrome (also works with Firefox Nightly (only Dev!))
- Go to `Settings` -> `Extensions` and activate `Developer mode` on the top right corner
- After activating `Developer mode`, hit `Load unpacked`
- Select the whole directory and the dark design is automatically enabled
- To see the rainbow line, go again to `Settings` -> `Appearance` and activate `Show bookmarks bar`
